# SRE fundamentals

## Objectives

Translate a user experience into a measurable target, make reliability an engineering decision, and improve systems after failures without blame.

Start with [SRE principles](sre-principles.md), then build an SLO and alert policy with [SLIs, SLOs, and SLAs](sli-slo-sla.md). Use [incident management](incident-management.md) when a risk becomes an event.
