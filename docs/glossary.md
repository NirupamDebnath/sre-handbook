# Glossary

- **Availability:** fraction of eligible events that meet a defined success condition.
- **Blast radius:** scope of users/systems affected by a change or failure.
- **Error budget:** permitted unreliability implied by an SLO.
- **RPO:** maximum tolerable data loss measured in time.
- **RTO:** target time to restore a service after disruption.
- **SLI/SLO/SLA:** measured indicator / internal objective / external agreement.
- **Toil:** manual, repetitive, automatable work without enduring value.
- **Workload identity:** short-lived cloud credentials associated with a workload, not a human key.
