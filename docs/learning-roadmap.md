# Learning roadmap

## Twelve-week loop

1. **Weeks 1–2 — measure reliability:** define user journeys, SLIs, SLOs, and a burn-rate policy.
2. **Weeks 3–4 — debug foundations:** practice Linux resource and TCP/DNS investigations in a disposable environment.
3. **Weeks 5–7 — operate Kubernetes/EKS:** scheduling, identity, CNI capacity, rollouts, and upgrades.
4. **Weeks 8–9 — deliver safely:** Terraform review, CI quality gates, Helm releases, and GitOps reconciliation.
5. **Weeks 10–11 — observe systems:** instrument a request path; investigate an induced latency failure.
6. **Week 12 — communicate:** run scenario and leadership interview drills aloud; write a concise postmortem.

For each week: read one guide, complete one lab, create one one-page cheat sheet, and answer one scenario with evidence and trade-offs. Revisit weak areas using the [interview track](interview-prep/index.md).
